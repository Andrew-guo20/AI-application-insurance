一、linux 环境安装
1.安装VMware	https://support.broadcom.com/group/ecx/downloads   	下载要登录账号 gmail email （下载的好麻烦）
	官网下载地址（VMware Workstation Pro 课程里的要许可证密钥） https://cf.comss.org/download/VMware-workstation-full-17.6.4-24832109.exe（不用汉化）
	（安装到D盘，新建一个目录）
	①Hyper‑V 是微软的虚拟化技术。底层的虚拟机监控程序负责分配 CPU、内存等资源，让虚拟机在 Windows 上运行
	②Device Guard、Credential Guard（凭据保护） 用虚拟化隔离某些登录凭据
	③WHP（Windows Hypervisor Platform） 是 Windows 提供给 VMware 这类第三方虚拟机软件的接口。勾选安装器里的 WHP 选项后，VMware 就可以通过这个接口使用 Windows 已启用的虚拟化引擎，同时保留你的 WSL 2 环境
	④彻底卸载神器 geek / CCleanner

2.挂载linux环境 
	①设置 - 网络和internet - 高级网络设置 - 检查电脑 VMware 的虚拟网卡
	②VMware 汉化 —— a.https://github.com/Kuroba-Sayuki/VMware-Workstation-Chinese-Localization  
					     b.在 GitHub 项目页点 Code → Download ZIP，解压后找到 VMware Workstation Messages 里的 zh_CN 文件夹 
					     c.把整个 zh_CN 文件夹放进 D:\develop\VMware\messages
					     d.右键 VMware 快捷方式 → 属性 → 快捷方式，把「目标」改成下面这行。点「确定」，再用这个快捷方式启动
							"D:\develop\VMware\vmware.exe" --locale zh_CN
	③VMnet1 默认用于仅主机模式（可以让Windows 和虚拟机互通，同一虚拟网络里的虚拟机也能互通；虚拟机默认不能上午）
	    VMnet8 默认用于 NAT 模式（可以让Windows 和虚拟机互通，同一虚拟网络里的虚拟机也能互通；虚拟机可以上网，借用 Windows 电脑的网络）
	④镜像解压不了，可能是windows自带解压工具识别格式出错，把外层.rar当成了.zip读取，所以报错。用7-zip
	⑤VMware 子网配置：	a.子网 IP 192.168.150.0  和 子网掩码 255.255.255.0 定义 VMnet8的网段。
					      	b.192.168.150.0/24  ; IP 地址的前三组数字 192.168.150 表示网段，最后一组用来区分设备	; '/24' 表示 掩码为 255.255.255.0
					      	'/24' 表示从左往右，子网掩码的前 24 位是 1，剩下的位是 0 ;IPv4 一共有 32 位，写成 4 组，每组 8 位。把这 24 个 1 按每组 8 位排开，正好填满前三组
						掩码里的 1 标记必须相同的位，`0` 标记可以变化的位 ; '/25' 网段范围就变成了 0 ~ 128
						c.DHCP（动态主机配置协议）让设备接入网络时自动拿到 IP 地址和其他网络设置
	⑥镜像解压好后，记得移到D盘，用一个目录专门管理 VM虚拟机环境
	⑦镜像安装光盘 下载地址 https://mirrors.ustc.edu.cn/centos-vault/7.9.2009/isos/x86_64/CentOS-7-x86_64-Minimal-2009.iso（由于镜像太大，上传不到github）
		a.安装光盘下载好后，打开 VMware ，Ctrl+N 选择 ‘典型’
		b.选择「安装程序光盘映像文件（ISO）」，浏览到 安装光盘 的路径
		c.给新虚拟机选一个单独的目录，完成向导后启动安装；安装完后启动虚拟机，会初始化（设置语言、配置、root用户/yu1234），login登录成功后，关闭客户端-编辑虚拟机设置，直接移除掉CD/DVD (IDE)，确定后重启虚拟机，能进入登录界面，即可删除安装光盘，建议不删除，将其放在VM文件夹中
		d.ip -4 addr show scope global 查看ip；没有输出的话，运行 nmtui 选 Activate a connection 启用网卡，进行设置页面
3.安装SSH连接工具：Linux服务器一般都是在远程的机房部署的，我们要操作服务器，不会每次都跑到远程的机房里面操作，而是会直接通过SSH连接工具进行连接操作
	①SSH 是 Secure Shell（安全外壳协议） 的缩写， 是一种加密的远程登录和远程操作协议，是 Linux/Unix 服务器运维中最常用的安全连接方式之一
	②官网下载 FinalShell https://www.hostbuf.com/ ，用 FinalShell 连接linux服务器，要先启动服务器（虚拟机）
